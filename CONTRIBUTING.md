# Contributing to MedOmni

MedOmni is developed in a private repository. This public repository is an export of each release, and every commit in it keeps its author.

A pull request here:

1. is checked by CI and reviewed by the MedOmni team;
2. once merged here, is brought into development under your name;
3. ships in the next release.

Contributions add agents, datasets, tasks or encoders. They don't change Core or the contracts: for a contract change, such as a new family, open an issue first. Work that should stay in your own repository can be a plug-in package instead.

The steps for each piece are in [Contribute](docs/guides/contribute.md).
