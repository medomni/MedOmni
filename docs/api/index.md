# Code map

v0.2.0 is not a Python package: there is nothing to import. This page lists each folder of the repository and its entry points.

## data_task/

Owned by Data & Task. Turns raw datasets into tasks.

| Path | Is |
|---|---|
| `families/`, `family_alias.yaml` | The family registry. |
| `data_roots.yaml` | Where each dataset is on this machine. |
| `taskbuilder/specs/` | Task specs: 30 types with their `-mini` and `-full` modes. |
| `taskbuilder/adapters/` | One reader per dataset. |
| `taskbuilder/registry/` | Metrics, label derivations, leakage rules, stream maps. |
| `taskbuilder/intake/` | Proposal intake: `compile.py`, `freeze.py`. |
| `taskbuilder/emit.py`, `validate.py`, `pin_batch.py` | Spec tasks: emit, check, pin. |
| `taskbuilder/emit_atomic.py` | Atom tasks, one per type and patient, per variant. |
| `tasks/batches/` | Pinned batches. |

## data_manifest/

The data plane the atomic builder reads: which files exist for each subject, in `dataplane/`.

## perception/

Owned by Perception. The encoders and the gateway.

| Path | Is |
|---|---|
| `encoders/<family>/<encoder>/` | One encoder: adapter, card, Dockerfile, test data. |
| `encoders.yaml` | The encoder index, generated by `registry.py index`. |
| `registry.py` | Validate, build, test and report on encoders. |
| `gateway/` | The HTTP gateway and its container pool. |
| `runtime/` | The shared encoder runtime and family decoding. |
| `spec/` | Card schema, evidence schema, container and service API specs. |
| `deployment.yaml` | The gateway's settings on this machine. |

## harness/

Runs agents on atom tasks under Harbor and scores them.

| Path | Is |
|---|---|
| `experiments/` | One yaml per experiment. |
| `build.py` | `emit`, `import`, `status`. |
| `harbor/base.yaml`, `harbor/agents/` | Harbor settings shared by every job, and one file per agent. |
| `models.yaml` | Every model evaluated, with the names its provider serves. |
| `perception-image/` | The perception sidecar image. |
| `formatcheck/` | The shared atom `tests/`: a format check that never scores. |
| `score.py`, `metrics.py` | The scorer and its metrics (AUC, QWK, MAE). |
| `analyze.py` | Ledger to experiment tables. |
| `prerun/` | Generated prerun sheets, signed before launch. |
| `config.yaml` | Machine settings: runs folder, keys file. |
| `legacy/` | The retired in-house runner. Nothing imports it. |

## assurance/

Owned by Assurance. `audit_matrix_v2/` holds the audit matrix: assets × criteria × auditors, with verdicts bound to fingerprints.

## runs/

Every trace and the ledger (`ledger/results.jsonl`). Local only: git ignores everything here except its README.

## internal_docs/

The MedOmni team's roadmaps, design references and reports. Not part of this site.
